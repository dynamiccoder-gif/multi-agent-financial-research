# Multi-Agent Financial Research System

Intelligent financial analysis platform combining ML, sentiment analysis, and RAG.
# Feature Engineering Documentation

## Features Generated
- Daily returns (1d, 5d, 20d)
- Moving averages (SMA 5, 10, 20)
- Volatility and momentum
- RSI and MACD indicators
- NIFTY-relative features
- Sector-aware features
- Sentiment scores
# Sentiment Analysis Documentation

## Sentiment Methodology
- Rule-based baseline using VADER
- FinBERT fine-tuned model
- Daily aggregation by company
